## 📌 معرفی

**Meli-Action** یک مجموعه قدرتمند از **GitHub Actions** است که به شما امکان می‌دهد بدون نیاز به سرور اختصاصی و **بدون فیلترشکن**، فایل‌های خود را از سرویس‌های مختلف دانلود کنید.

> ✨ **فقط کافیست ریپوزیتوری را فورک کنید و در عرض چند کلیک، فایل مورد نظرتان را دانلود نمایید!**

---

## 🎯 چرا Meli-Action؟

| ویژگی | توضیح |
|-------|--------|
| 🌐 **بدون فیلترشکن** | تمام سرویس‌ها روی سرورهای گیت‌هاب (آمریکا/اروپا) اجرا می‌شوند |
| 💰 **کاملاً رایگان** | هیچ هزینه‌ای برای شما ندارد، از سرورهای رایگان GitHub استفاده می‌کند |
| ⚡ **فوق‌العاده سریع** | دانلود با پهنای باند گیت‌هاب (تا 100 مگابایت بر ثانیه) |
| 📦 **مدیریت هوشمند حجم** | تقسیم خودکار فایل‌های حجیم به چند قسمت |
| 🔄 **پشتیبانی از Resume** | ادامه دانلود از نقطه قطع شده |
| 🎨 **خروجی چندگانه** | ذخیره در ریپوزیتوری یا انتشار در GitHub Releases |
