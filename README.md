---

## 🚀 روش استفاده

**1.** کلیک **Fork** (بالای صفحه)

**2.** رفتن به تب **Actions** → انتخاب ابزار → **Run workflow**

**3.** پر کردن فرم (لینک، کیفیت، روش ذخیره)

**4.** دریافت فایل از `downloads/` یا **Releases**

---

## ⚙️ تنظیمات

**کوکی یوتیوب** (برای ویدیوهای محدود):
Settings → Secrets → Actions → YT_COOKIES


**تقسیم فایل**:
- فیلد `max_part_mb` = 90 تا 1900 مگابایت
