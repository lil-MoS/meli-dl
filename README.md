3. کلیک **Run workflow**
4. بعد از اتمام، فایل در پوشه `downloads/` ریپوزیتوری شما قرار می‌گیرد

## ❗ نکات مهم

- **مدت زمان اجرا:** هر اکشن حداکثر ۴۵ تا ۶۰ دقیقه زمان دارد (محدودیت GitHub)
- **حجم فایل:** بهتر است فایل‌ها زیر ۲ گیگ باشند. برای فایل‌های بزرگتر از تقسیم خودکار استفاده کنید.
- **فایل‌های اسپاتیفای:** نیاز به اجرای کانتینر Downtify دارد که ممکن است گاهی کند باشد.
- **گوگل پلی:** برای اولین استفاده نیاز به احراز هویت دارد (دستی در ریپو شما ذخیره می‌شود)
